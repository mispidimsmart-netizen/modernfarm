# PCB ট্যাবে ব্লক ও ওয়্যারিং ডায়াগ্রাম

PCB ডিজাইন (Flux.ai) ট্যাবে একটি নতুন কার্ড যোগ হবে: **"সিস্টেম ব্লক ডায়াগ্রাম ও ওয়্যারিং"** — চারটি প্রধান ব্লক এবং তাদের সংযোগ পরিষ্কারভাবে দেখাবে।

## ডায়াগ্রামের ব্লক

```text
 [ AC 220V ইনপুট ]
   fuse + MOV + earth
          |
   [ AC→DC পাওয়ার ]        5V 3A SMPS → AMS1117 3.3V,
   5V rail / 3.3V rail      SIM800L এর জন্য আলাদা 4.0V/2A + 1000µF
        |        |
        |        +-------------------+
        v                            v
 [ ESP32 কন্ট্রোল কোর ]  <--UART-->  [ GSM SIM800L ]
   ESP32-WROOM-32 38-pin              TX 23 / RX 19 (ডিভাইডার)
   + TFT ILI9341 (21,22,17,5)         RST → 10k পুল-আপ
        ^                |
        | ADC/GPIO       | GPIO → PC817 → ULN2803A
        |                v
 [ সেন্সর ইনপুট ]        [ রিলে ও অ্যালার্ম আউটপুট ]
  DHT22 x2 (4,16)         IN1..IN8 = 25,26,27,14,12,13,15,33
  MQ-137 (34), ZMPT (35)  ফ্যান/লাইট/হিটার/ফগার/অ্যালার্ম/
  LDR (36), YF-S201 (18)  স্প্রিংকলার/সার্কুলেশন + প্যানেল LED
  ওভাররাইড বাটন (32)      ফ্লাইব্যাক 1N4007, স্ক্রু টার্মিনাল 5.08mm
```

## কী থাকবে

1. **ইন্টারঅ্যাক্টিভ SVG ডায়াগ্রাম** — চারটি রঙিন ব্লক (AC→DC, ESP32+GSM, সেন্সর, রিলে/আলার্ম), তীরচিহ্নসহ সংযোগ, প্রতিটি তীরে সিগন্যাল লেবেল (যেমন "GPIO 25-33 → অপ্টো", "UART 23/19", "5V/3.3V রেল")। মোবাইলে হরাইজন্টাল স্ক্রল করা যাবে।
2. **প্রতি-ব্লক বিস্তারিত তালিকা** — অ্যাকর্ডিয়নে প্রতিটি ব্লকের কম্পোনেন্ট, পিন এবং ওয়্যারিং নিয়ম (আইসোলেশন, পুল-আপ, ডিভাইডার, গ্রাউন্ড স্টার-পয়েন্ট)।
3. **ডায়াগ্রাম ডাউনলোড** — SVG ফাইল ডাউনলোড বোতাম, যাতে Flux.ai/ইলেকট্রিশিয়ানকে দেওয়া যায়।
4. **কপি বোতাম** — একই সংযোগ তালিকা টেক্সট নেট-লিস্ট আকারে কপি করে Flux Copilot-এ পেস্ট করা যাবে।

## টেকনিক্যাল বিবরণ

- `src/data/fluxPcbGuide.ts`-এ নতুন এক্সপোর্ট: `DIAGRAM_BLOCKS` (id, শিরোনাম, সাবটাইটেল, আইটেম তালিকা) এবং `DIAGRAM_LINKS` (from, to, লেবেল, ধরন: power/signal/hv)। পিন নম্বরগুলো বিদ্যমান `PIN_MAP` থেকেই ডেরাইভ হবে, যাতে ফার্মওয়্যার বদলালে ডায়াগ্রামও মিলে যায়।
- নতুন কম্পোনেন্ট `src/components/admin/PcbBlockDiagram.tsx` — হাতে লেখা রেসপন্সিভ SVG (`viewBox`, `preserveAspectRatio`), শুধু সেমান্টিক টোকেন (`hsl(var(--primary))` ইত্যাদি) ব্যবহার করবে যাতে ডার্ক মোডেও পড়া যায়।
- `src/components/admin/FluxPcbDesignGuide.tsx`-এ কমপ্লায়েন্স চেকলিস্টের আগে নতুন কার্ড হিসেবে বসবে।
- `src/test/fluxPcbGuide.test.ts`-এ টেস্ট যোগ: প্রতিটি লিঙ্কের from/to বৈধ ব্লক, রিলে ব্লকে ঠিক ৮টি GPIO এবং সেগুলো `PIN_MAP` এর relay গ্রুপের সাথে হুবহু মিলছে, সেন্সর/GSM/ডিসপ্লে পিনও একইভাবে যাচাই।
- ফার্মওয়্যার, ডেটাবেস বা অন্য কোনো পেজে কোনো পরিবর্তন নেই।
